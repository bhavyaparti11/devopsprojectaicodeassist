# 📅 Project Plan & Agile Workflow

## Overview
This project was developed using an iterative approach, breaking the development cycle into distinct phases to ensure stability and continuous integration.

### Phase 1: Foundation & Setup
* Initialize Git repository and standard directory structure.
* Set up basic `index.html` and Node.js backend server.
* Ensure local routing and static file serving function correctly.

### Phase 2: Core Functionality & AI Integration
* Integrate Axios to handle external HTTP requests.
* Connect the backend to the Groq API endpoint.
* Implement error handling for API failures and manage environment variables securely.

### Phase 3: UI/UX & Frontend Polish
* Design a responsive CSS UI with a centered container and gradient background.
* Integrate `marked.js` for dynamic markdown formatting.
* Implement custom scrollbars and dark-mode code block styling to handle long AI responses.

### Phase 4: DevOps & CI/CD
* Implement a Git branching strategy.
* Configure GitHub Actions (`cicd.yml`) for automated pipeline execution.
* Validate Pull Requests and merge conflicts to ensure repository integrity.
