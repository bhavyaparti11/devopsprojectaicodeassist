# 📖 User Guide

Welcome to AI Code Assist! This tool acts as your personal senior developer, helping you review and understand code snippets instantly.

## How to use the tool:

1. **Input Code:** Locate the main text area in the center of the screen. Paste or type the code snippet you are currently working on into this box.
2. **Choose an Action:**
   * **Explain Code (Blue Button):** Click this if you do not understand what a piece of code does. The AI will return a simple, beginner-friendly explanation of the logic.
   * **Review Code (Pink Button):** Click this if you want the AI to check your code for bugs, missing semicolons, or logic errors. It will provide a concise list of improvements.
3. **Read the Output:** The results will appear in the scrollable box below the buttons. Code suggestions provided by the AI will be highlighted in dark blocks for easy reading.

*Note: The application requires an active internet connection to communicate with the Groq AI servers.*
